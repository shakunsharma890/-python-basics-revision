# 🐍 Chapter 3 — Strings

This chapter focuses on understanding and working with **strings in Python**.

I learned how strings are created, accessed, sliced, formatted, and manipulated using different operations and built-in methods.

---

## 📚 Topics Covered

### 🔹 1. String Basics

* What are strings?
* Creating strings
* Single quotes
* Double quotes
* Basic string operations

---

### 🔹 2. String Indexing

Learned how to access individual characters from a string using their index.

Topics covered:

* Positive indexing
* Negative indexing
* Accessing individual characters

Example:

```python
text = "Python"

print(text[0])
print(text[-1])
```

---

### 🔹 3. String Slicing

Learned how to extract a portion of a string using slicing.

Topics covered:

* Start index
* End index
* Step
* Positive slicing
* Negative slicing

Example:

```python
text = "Python"

print(text[0:3])
print(text[2:])
print(text[:4])
print(text[::2])
```

---

### 🔹 4. String Concatenation

Learned how to combine two or more strings using the `+` operator.

Example:

```python
first_name = "Shakun"
last_name = "Sharma"

name = first_name + " " + last_name

print(name)
```

---

### 🔹 5. String Repetition

Learned how to repeat strings using the `*` operator.

Example:

```python
text = "Python "

print(text * 3)
```

---

### 🔹 6. Escape Sequences

Learned how to use escape sequences to represent special characters inside strings.

Examples:

```python
print("Hello\nPython")
print("Hello\tPython")
print("He said \"Hello\"")
```

Common escape sequences practiced:

* `\n` — New line
* `\t` — Tab
* `\"` — Double quote
* `\'` — Single quote
* `\\` — Backslash

---

### 🔹 7. Formatted Strings

Learned how to insert variables and expressions into strings using **f-strings**.

Example:

```python
name = "Shakun"
age = 21

print(f"My name is {name} and I am {age} years old.")
```

---

### 🔹 8. String Methods

Practiced different built-in methods for manipulating and analyzing strings.

Some of the methods covered include:

```python
upper()
lower()
strip()
replace()
split()
find()
count()
```

Example:

```python
text = "python programming"

print(text.upper())
print(text.replace("python", "Python"))
```

---
